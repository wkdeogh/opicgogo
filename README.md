# opicgogo

기존 모의고사·실전 연습에 `opic종합정리.md`의 전체 학습 내용을 연결한 정적 웹 앱입니다.

## 실행

```sh
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 별도 패키지 설치나 서버 API는 필요하지 않습니다.

## 학습 자료 갱신

최신 기준은 `opic종합정리.md`입니다. 원문을 수정했다면 다음 명령으로 생성 파일과 누락 여부를 확인합니다.

```sh
node scripts/build-course.mjs
node scripts/verify-course.cjs
```

Windows에서 Node의 경로 해석이 제한되는 환경은 두 명령에 `--preserve-symlinks-main --preserve-symlinks`를 추가합니다.

- `course-data.js`: 원문 전체, 단원별 콘텐츠, 표, 회상 카드, 퀴즈를 생성합니다. 직접 편집하지 않습니다.
- `course-sync.js`: 기존 모의고사 답변 중 겹치는 내용을 최신 예문으로 갱신하고 답변 템플릿과 추가 말하기 질문을 연결합니다. 단원 구조가 변경되면 연결된 단원 번호도 확인합니다.
- `course-app.js`, `course.css`: 학습 메뉴, 회상 모드, 검색, 진도와 즐겨찾기 UI입니다.
- `mp3/`: 쉐도잉용 음성 파일입니다.

검증은 원문 해시와 전체 텍스트 재조합, 학습 내용 1,178개 행의 렌더링, 97개 단원, 190개 회상 문제, 27개 추가 말하기 질문, 기존 모의고사 150문항, 자바스크립트 구문, 로컬 파일 경로를 확인합니다. 단원 제목은 원문 계층을 유지하면서 메뉴에 맞게 표시합니다.

학습 진도·즐겨찾기는 `opicCourseProgress`에 저장됩니다. 기존 모의고사·퀴즈·Survey의 저장 키는 유지합니다. 녹음은 현재 브라우저 세션에서 재생할 수 있으며 서버로 전송하지 않습니다.
