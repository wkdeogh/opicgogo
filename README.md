# opicgogo

기존 모의고사·실전 연습에 `opic종합정리.md`의 전체 학습 내용을 연결한 정적 웹 앱입니다.

## 실행

```sh
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 별도 패키지 설치나 서버 API는 필요하지 않습니다.

## 학습 자료 갱신

최신 기준은 `opic종합정리.md`입니다. 원문을 수정했다면 다음 명령으로 생성 파일과 누락 여부를 확인합니다.

```sh
node scripts/build-course.mjs
node scripts/verify-course.cjs
```

Windows에서 Node의 경로 해석이 제한되는 환경은 두 명령에 `--preserve-symlinks-main --preserve-symlinks`를 추가합니다.

- `course-data.js`: 원문 전체, 출처별 콘텐츠 조각, 표, 예문과 퀴즈를 생성합니다. 직접 편집하지 않습니다. 조각 번호는 출처 추적과 기존 링크를 위한 내부 식별자입니다.
- `course-layout.js`: 관련 출처를 학습 화면으로 묶습니다. 원문 구조가 달라지면 이 배치와 `course-sync.js`의 연결도 확인합니다.
- `course-sync.js`: 기존 모의고사 답변 중 겹치는 내용을 최신 예문으로 갱신하고 답변 템플릿과 추가 말하기 질문을 연결합니다.
- `course-app.js`, `course.css`: 유형별 답변 정리, 영작 노트, 표현 비교표, 주제별 스크립트와 검색 UI입니다.
- `mp3/`: 쉐도잉용 음성 파일입니다.

학습은 내용을 읽고 연습하는 방식에 따라 묶었습니다. 유형별 출제 특징과 답변 흐름은 함께 읽고, 문법은 한 주제의 모든 예문을 나란히 보거나 직접 영작합니다. 표현은 비교표에서 찾고 가릴 수 있으며, 롤플레이는 한 상황의 질문·문제 해결·관련 경험을 한 페이지에 표시합니다. Survey는 시험 전 확인 화면의 접힌 참고 항목입니다.

최신 문서의 `유형별 예시 문제와 답변 스크립트`부터는 절·제목으로 학습 화면과 연습 데이터를 연결합니다. 장소별 답변 1·2는 함께 표시하며, 현재 원문에 질문만 있는 사물 문제에는 이전 답변을 붙이지 않습니다. 이전 스크립트 링크는 대응하는 최신 학습 화면으로 이동합니다.

검증은 원문 해시·전체 텍스트 재조합뿐 아니라 실제 화면 렌더러에서 모든 학습 내용이 표시되는지 확인합니다. 출처 배치, 영작 화면, 장소별 답변 쌍, 롤플레이 세 답변 묶음, 기존 링크의 새 화면 연결, 퀴즈·말하기·모의고사 데이터, 자바스크립트 구문과 로컬 파일 경로도 검사합니다. 잘못된 문서가 반영된 커밋 `90d9324`와 대조하여 폐기된 영문 문단이 활성 학습·템플릿·모의고사·말하기 자료에 남지 않았는지도 검사합니다.

영작 답안과 최근 학습 위치는 `opicStudyDesk`에 저장됩니다. 이전 학습 조각의 완료·즐겨찾기 UI는 제거했으며, 기존 모의고사·퀴즈 기록은 유지합니다. 녹음은 현재 브라우저 세션에서 재생할 수 있으며 서버로 전송하지 않습니다.
